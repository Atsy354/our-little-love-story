# Our Little Photobooth ♡

Website photobooth anniversary dengan 10 tema, kamera, upload galeri, retake per frame, live preview, dan ekspor PNG lokal.

## Hosting di GitHub Pages
1. Unggah `index.html` ke root repository GitHub.
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu Save.
4. Buka URL GitHub Pages yang ditampilkan GitHub.

Kamera membutuhkan HTTPS (GitHub Pages sudah HTTPS) atau localhost. Foto diproses lokal di browser dan tidak diunggah ke server.
